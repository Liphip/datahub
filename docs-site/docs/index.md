# DataTurntable Documentation

This documentation portal is designed for both:

- **Beginners** with little technical background
- **Administrators/operators** running production environments

## Start Here

- New users: open **English > Beginner Guide** or **Deutsch > Einsteiger-Guide**.
- New users wanting click-by-click help: open **UI Controls Reference** and **Step-by-Step Tasks**.
- Administrators: open **Administrator Guide** and **Operations Runbook**.

## What this portal covers

- onboarding and everyday usage
- tenant/role management
- module and pipeline lifecycle
- monitoring, logs, and incident response
- backup and recovery
- practical troubleshooting checklists

## Deployment model

This is a standalone MkDocs Material site, served by a dedicated `docs` service.

- Subdomain: `docs.localhost` (local), `docs.<your-domain>` (prod)
- Fallback route: `/docs`
