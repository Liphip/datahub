# Beginner Guide

This page assumes little to no prior platform experience.

## Your first practical workflow

1. Create a simple module.
2. Create a pipeline using that module.
3. Trigger one run.
4. Open Data Explorer and verify output.
5. Check logs if anything fails.

## If you see errors

- confirm you are in the correct tenant
- verify you have read/write permissions
- check pipeline run details for exact failure stage

## Friendly tips

- Start with one small change at a time.
- Use clear names: `team-purpose-env`.
- Ask admin to review before production actions.
- Keep screenshots and timestamps when reporting problems.

## Glossary shortcuts

- latency = time to complete request/run
- retry = automatic additional attempt
- alert channel = destination for notifications
