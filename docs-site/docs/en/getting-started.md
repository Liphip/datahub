# Getting Started

## First login checklist

1. Sign in to the platform.
2. Confirm the selected tenant in the top bar.
3. Open Dashboard and verify there are no critical failures.
4. Check API availability and health status.

## Important concepts

- **Tenant**: your workspace boundary.
- **Module**: reusable processing building block.
- **Pipeline**: ordered chain of modules.
- **Run**: one execution of a pipeline.

## Safe way to begin

- work in non-production tenant first
- avoid deleting tables/modules until reviewed
- capture notes for every change

## Recommended learning path

1. Beginner Guide
2. Modules
