# Glossary

- **Tenant**: isolated workspace scope
- **Module**: reusable processing unit
- **Pipeline**: ordered module chain
- **Run**: single pipeline execution
- **Connector**: external integration definition
- **Prometheus**: metrics system
- **Grafana**: dashboard and analysis UI
- **Loki**: log storage/query backend
- **RPO**: acceptable data-loss window
- **RTO**: restoration time objective
