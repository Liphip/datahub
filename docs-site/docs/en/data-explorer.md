# Data Explorer

## Use cases

- quick data validation
- operational anomaly checks
- export evidence for incidents

## Query guide

1. Select tenant + table.
2. Set time window and row limit.
3. Run query and review summary cards.
4. Inspect trend/distribution charts.
5. Export CSV or JSON if needed.

## Safety notes

- restrict table create/delete permissions
- use approvals for destructive production actions
