# Glossar

- **Mandant**: isolierter Arbeitsbereich
- **Modul**: wiederverwendbare Verarbeitungseinheit
- **Pipeline**: geordnete Modulkette
- **Run**: einzelne Pipeline-Ausfuehrung
- **Konnektor**: externe Integrationsdefinition
- **Prometheus**: Metriksystem
- **Grafana**: Dashboard- und Analyseoberflaeche
- **Loki**: Log-Backend
- **RPO**: tolerierbares Datenverlustfenster
- **RTO**: Zielzeit fuer Wiederherstellung
