# Administratoren-Guide

## Kernaufgaben

- Mandanten- und Rollenverwaltung
- sichere Releases mit Rollback-Plan
- Monitoring/Logging-Qualitaet
- Backup/Restore-Tests

## Zugriffsgovernance

### Benutzer-Onboarding

1. Benutzer anlegen
2. minimale Rolle zuweisen
3. effektive Rechte testen
4. Freigabe dokumentieren

### Regelmaessige Reviews

- woechentlich privilegierte Konten
- monatlich alle Mitgliedschaften
- sofort bei Offboarding

## Produktionsaenderungen

Vorher:

- Rollback pruefen
- Baseline-Metriken pruefen
- Wartungsfenster abstimmen

Nachher:

- Soak-Phase monitoren
- Fehler-/Latenztrends vergleichen
