# Einsteiger-Guide

Diese Seite richtet sich an Nutzer ohne tiefes Vorwissen.

## Erste praktische Uebung

1. Einfaches Modul erstellen
2. Pipeline mit dem Modul erstellen
3. Einen manuellen Run starten
4. Ergebnis im Daten-Explorer pruefen
5. Bei Fehlern Logs in Grafana anschauen

## Wenn etwas nicht funktioniert

- Mandantenkontext pruefen
- Rechte pruefen
- Run-Details der Pipeline analysieren

## Tipps

- in kleinen Schritten arbeiten
- klare Namen verwenden
- vor Produktion ein Review einholen
