# Konnektoren und Alarme

## Konnektoren

Konnektoren definieren Integrationen und Zugangskontexte.

Best Practices:

- Zugangsdaten pro Umgebung trennen
- nach Rotation Verbindung testen
- Timeouts explizit setzen

## Alarme

Signalqualitaet vor Alarmmenge.

Empfehlung:

1. Kanal konfigurieren
2. umsetzbare Regel definieren
3. Testtrigger ausfuehren
4. Zustellhistorie pruefen
