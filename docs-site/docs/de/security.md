# Sicherheitsgrundlagen

## Zugriffskontrolle

- keine geteilten Admin-Logins
- Least-Privilege-Rollen
- regelmaessige Rechte-Reviews

## Secrets

- nicht in Git speichern
- planmaessig rotieren
- bei Exposure sofort widerrufen

## Endpunkt-Haertung

- nur benoetigte Routen freigeben
- Admin-Endpunkte absichern
- Auth-Fehler aktiv monitoren
