# Configuration Reference

Runtime configuration covers the application database, Kafka, Redis, runtime role,
pipeline-data database, Grafana provisioning, Docker module limits, and MQTT UI
defaults. Production secrets must be injected by the deployment platform rather
than committed to the repository.

The authoritative variable table is in the
[repository configuration reference](https://github.com/YOUR_ORGANIZATION/dataturntable/blob/main/docs/development/configuration-reference.md).
