# Sicherheitsgrundlagen

## Identitaet und Zugriff

- eindeutige Benutzerkonten erzwingen
- keine geteilten Admin-Logins
- nur noetige Rechte vergeben

## Secrets

- Secrets nicht in Git speichern
- regelmaessig rotieren
- bei Verdacht sofort widerrufen

## Betriebs-Haertung

- oeffentliche Endpunkte minimieren
- Auth-/Permission-Fehler monitoren
- Abhaengigkeiten aktuell halten
