# Glossar

- **Mandant**: isolierter Arbeitsbereich mit eigenem Rechte- und Datenscope.
- **Modul**: wiederverwendbare Einheit fuer Import/Verarbeitung/Alarm/Export.
- **Pipeline**: geordnete Kette aus Modulen.
- **Run**: eine Ausfuehrung einer Pipeline.
- **Konnektor**: Integrationsendpunkt inkl. Zugangskontext.
- **Lineage-Diagnose**: Metadaten zur Fehleranalyse von Runs/Defaults.
- **Exporter**: Komponente mit Prometheus-Metrikausgabe.
- **Prometheus**: Metriksystem fuer Sammlung und Queries.
- **Grafana**: Dashboard- und Analyseoberflaeche.
- **Loki**: Log-Backend.
- **Promtail**: Agent fuer Log-Sammlung.
- **RPO**: maximal tolerierbares Datenverlustfenster.
- **RTO**: Zielzeit fuer Wiederherstellung.
