# Erste Schritte

## 1. Ersteinrichtung

1. Backend und Frontend bereitstellen.
2. Einmalig `/setup` ausfuehren.
3. Ersten Superadmin anlegen.
4. Anmelden und Mandantenkontext pruefen.

## 2. Checkliste fuer die ersten 30 Minuten

- API-Health (`/q/health`) und Metriken (`/q/metrics`) pruefen.
- Dashboard auf kritische Fehlersignale pruefen.
- Stammmandant und Untermandant erstellen.
- Testmodul und Testpipeline anlegen.
- Testlauf ausfuehren und Run-Details pruefen.

## 3. Sichere Standards

- Schreibrechte in Produktion minimieren
- Rollen strikt mandantenbezogen vergeben
- Monitoring und Logging sofort aktiv nutzen
- On-Call-Verantwortung je Mandant festlegen
