# FAQ

## Ist `/docs` Teil der React-App-Routen?

Nein. `/docs` ist eine eigenstaendige statische Doku-Seite.

## Kann die Doku separat gehostet werden?

Ja. `frontend/public/docs` kann auf jedem statischen Host bereitgestellt werden.

## Wie fuegen wir eine neue Sprache hinzu?

Neuen Sprachordner anlegen (z. B. `/fr`) mit `README.md`, `_sidebar.md`, `_navbar.md` und uebersetzten Seiten.

## Wo liegen die vollstaendigen Markdown-Handbuecher?

In `docs/user/en/user-guide.md` und `docs/user/de/benutzerhandbuch.md`.
