# Runbooks und Wartung

## Tägliche Pruefungen

- naechtliche Fehlerfaelle sichten
- Alarmzustellung pruefen
- Top-Ressourcenverbraucher pruefen
- geplante Jobs kontrollieren

## Wöchentliche Pruefungen

- Mandanten-/Benutzeraenderungen auditieren
- alte Modulversionen aufraeumen
- Backup-Erfolg validieren
- Dashboard-Signalqualitaet pruefen

## Release-Runbook

1. Wartungsfenster kommunizieren.
2. Kritischen Zustand sichern (Snapshot/Export).
3. Nicht-Produktion validieren.
4. Produktion stufenweise ausrollen.
5. Soak-Phase mit Monitoring begleiten.
