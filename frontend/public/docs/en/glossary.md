# Glossary

- **Tenant**: isolated workspace with its own permissions and data scope.
- **Module**: reusable unit performing import/process/alert/export logic.
- **Pipeline**: ordered chain of modules.
- **Run**: one execution of a pipeline.
- **Connector**: integration endpoint and credential context.
- **Lineage diagnostics**: metadata helping debug run/default behavior conflicts.
- **Exporter**: component exposing metrics in Prometheus format.
- **Prometheus**: metrics storage and query system.
- **Grafana**: dashboards and observability UI.
- **Loki**: log aggregation backend.
- **Promtail**: log collection agent.
- **RPO**: maximum acceptable data loss window.
- **RTO**: target time to restore service.
