# Security Basics

## Identity and Access

- enforce unique user accounts
- avoid shared admin logins
- grant only required abilities

## Secrets

- keep secrets in secret stores
- rotate regularly
- revoke immediately on exposure

## Operational Hardening

- restrict public ingress to required routes
- monitor auth and permission errors
- keep dependency versions patched

## Audit Readiness

Keep evidence for:

- access approvals
- role changes
- incident timelines
- backup/restore tests
