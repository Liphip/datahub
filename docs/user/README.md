# User Documentation

This folder contains exhaustive user-facing documentation in multiple languages.

## Available Languages

- English: `docs/user/en/user-guide.md`
- German: `docs/user/de/benutzerhandbuch.md`

## Scope

The user guides cover:

- onboarding and navigation
- tenants and permissions
- modules and pipelines
- data explorer and exports
- connectors and alerts
- monitoring, logs, and diagnostics
- backup/recovery and troubleshooting
- day-2 operations and best practices

## Web Version

An interactive static docs site is available at `/docs`.

- Source files: `frontend/public/docs/`
- Rendering framework: Docsify
- Languages: English and German
